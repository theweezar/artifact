Tại sao LCP tệ hơn sau Next.js?
Cơ chế gây ra LCP regression trong Lighthouse mobile simulation
⚡
Root cause chính: Next.js App Router bundle toàn bộ CSS thành các chunk render-blocking. Homepage hiện có 20 blocking CSS requests (1,116 KB), search page có 36 requests (1,446 KB). Laravel cũ chỉ có ~3–5 CSS files nhỏ hơn. Trong Lighthouse mobile simulation (throttled ~1.6 Mbps), trình duyệt phải download hết CSS mới render được bất kỳ pixel nào.
